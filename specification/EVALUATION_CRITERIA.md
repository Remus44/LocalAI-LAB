# Evaluation
Atomic score: 0 incorrect, 1 correct after one correction, 2 correct first attempt; null unmeasured. Record first attempt separately. Any scope violation is a failure. Compare per category, not only aggregate. Same model digest, prompt version, context, seed and temperature when possible; log truncation and thinking settings. Repeat promising cases.
Project: external acceptance tests, regression tests, manual review and smoke checks. No credit for merely claiming tests passed. Do not expose external tests to worker. Run untrusted code only in a disposable restricted environment, without credentials or network.
Pilot: record base commit, task contract, model, timing, input/output/cache token counts where available, local GPU peak, cloud preparation/review/correction/fallback, scope/build/lint/tests/smoke/review. Compare against equivalent cloud-only task. Token counts are not necessarily quota units. Missing data remains null.
Provisional targets: 80% first-pass within a qualified category, 100% mandatory gates on accepted work, 10% net cloud capacity saving if measurable. Ten comparable real tasks is an initial signal, not statistical proof. Record latency and energy separately. No hardware purchase.
